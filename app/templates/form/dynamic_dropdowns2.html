recipe นี้สาธิตการสร้าง dropdown select ที่มีรายการเชื่อมโยงกัน 3 รายการโดยใช้ htmx ทั้งหมด

recipe นี้ใช้การส่ง form data ทั้งหมดแทนการส่งเฉพาะ select data เพื่อความสะดวกในการตรวจสอบ กำหนดโดย hx-include="closest form" และใช้ hx-trigger เพื่อตรวจสอบว่า select อันใดมีการเปลี่ยนแปลง โดย hx-trigger สามารถตรวจสอบได้ใน view โดยใช้ request.headers.get('HX-Trigger') นอกจากนั้นยังใช้เทคนิค hx-swap-oob เพื่อความสะดวกในการ swap dropdowns ทั้งหมด เนื่องจาก hx-swap-oob=true จะนำ element นั้นไปแทนที่ ณ ตำแหน่งที่มี id ตรงกันโดยอัตโนมัติ ดังนั้นในการตั้งค่า hx-target จึงตั้งให้เป็น #province เท่านั้นได้
